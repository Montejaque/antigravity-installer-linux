# Política de seguridad

- Los enlaces se obtienen de https://antigravity.google/download.
- Solo se aceptan enlaces HTTPS de storage.googleapis.com y edgedl.me.gvt1.com.
- No se utilizan mirrors ni repositorios de terceros.
- No se solicitan credenciales de Google.
- No se necesitan permisos root y no se escribe en /usr.
- Si la página oficial cambia y no se pueden validar los paquetes, la descarga se detiene.

Comunica vulnerabilidades mediante GitHub Issues, evitando incluir datos personales o credenciales.
