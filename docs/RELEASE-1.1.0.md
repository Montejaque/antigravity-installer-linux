# Antigravity Installer 1.1.0

- Instala Antigravity App, Antigravity IDE o ambos.
- Consulta por separado las versiones instaladas y publicadas.
- Actualiza o desinstala cada componente sin afectar al otro.
- Repara los accesos del menú de aplicaciones.
- AppImage x86_64 compilada en Ubuntu 20.04 mediante GitHub Actions.
- Guía de ayuda PDF incluida en los activos de la Release.
